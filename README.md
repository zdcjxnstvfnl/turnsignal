## 🕹️ Overview

TurnSignal monitors your real-world rotation and displays a visual indicator reminding you to physically turn back before your headset cable becomes twisted.

Whether you're a newcomer or a veteran, TurnSignal provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Rotation Tracker** | Monitors cumulative rotation and shows a directional arrow |
| **Custom Threshold** | Set the rotation angle that triggers the warning overlay |
| **Fade-in Alert** | Overlay fades in smoothly to avoid interrupting gameplay |
| **Always on Top** | Displays above any SteamVR content so you never miss it |
